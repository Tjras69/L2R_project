LEFT2RIGHT EDUCATION HUB (PHP + MySQL) - LAMPP setup
1. Copy this folder to /opt/lampp/htdocs/l2r
2. Start Apache and MySQL:  sudo /opt/lampp/lampp start
3. Open http://localhost/l2r/install.php once (creates the database and sample content)
4. Open http://localhost/l2r/
Admin login: admin@l2r.local / admin123  (then use "Manage content" on the dashboard)
Database settings are at the top of config.php. Delete install.php when finished.
To use your own logo, replace assets/logo.svg (or change the img paths).
